🚨 常见问题排查
────────────────────────────────────────────────────────────────

❓ 机器人转不到目标方向?
   → 检查 goal_yaw_ 是否正确保存
   → 检查 KP_YAW 是否足够大(试试1.5)
   → 检查 YAW_TOL 是否太严格(试试0.15)

❓ 机器人路径偏离?
   → 检查 gx/gy 赋值是否正确(修复后应该正确)
   → 检查前瞻距离(LOOKAHEAD_DIST)
   → 检查路径点间距(太大会导致不稳定)

❓ 运动不平滑?
   → 检查是否接近目标时突然转向
   → 减小 KP_YAW 或增大 LOOKAHEAD_DIST
   → 增大 transition_dist 参数

❓ 编译失败?
   → 运行 catkin_make 整个工作空间
   → 检查 ROS 环境: source devel/setup.bash

🔄 性能微调建议
────────────────────────────────────────────────────────────────

如果运动太敏捷(频繁抖动):
  ↓ 减小 KP_YAW (1.2 → 1.0)
  ↑ 增大 LOOKAHEAD_DIST (0.5 → 0.6)
  ↑ 增大 transition_dist (增加平滑过渡)

如果运动太缓慢(响应不足):
  ↑ 增大 KP_YAW (1.2 → 1.4)
  ↓ 减小 LOOKAHEAD_DIST (0.5 → 0.4)
  ↓ 减小 GOAL_TOL (0.25 → 0.2)

如果无法精确对接:
  ↓ 减小 YAW_TOL (0.1 → 0.05)
  ↑ 增大 KP_YAW (1.2 → 1.5)
  ↑ 增大 KI_YAW (0.0 → 0.1)
